VEILRAG / A BOUNDED LOCAL BUILD

Inspect what leaves.
Reveal with intent.

Replace declared synthetic literals across a request, inspect the sanitized frames sent to a local child fixture, and explicitly restore an allowed response for a configured recipient.

Read the original VeilRAG blueprint

Partial local implementation. Only exact, case-sensitive declared literals are replaced. Remaining case and NFKC-equivalent variants of those declared literals are conservatively rejected, not rewritten. This is not general PII detection, a formal privacy guarantee, authenticated authorization or an external-provider integration. A local encrypted alias vault and a child-process fixture are exercised with synthetic data; no provider is contacted.

01 / DECLARE

Make the boundary explicit

Declare every exact literal this fixture must protect. The same aliases are used across the query, context, message history and structured tool arguments. A remaining NFKC/lowercase-equivalent variant stops protection before any frames, vault entry or protection audit event is saved for that input. Correct the frames to use the exact declared spelling, then prepare a fresh command. Undeclared sensitive values remain outside this build’s protection.

The command ID binds this exact input. Retry unchanged input to recover a lost response. Changed input needs a new command ID.

What is being exercised

Protection stores the alias mapping encrypted locally. Generation receives sanitized frames without the alias table. The output is checked before any restoration is permitted.

Generator profiles are fixed synthetic child fixtures. An exact literal leak, declared-literal variant or foreign alias blocks the result; these are adverse-case demonstrations, not model evaluations. Variant comparison uses NFKC normalization followed by lowercase matching. It is not full Unicode case folding, decoding or automatic entity detection.

Receipt exports contain sanitized source evidence and plaintext protocol metadata such as timestamps and IDs. Those metadata values are not confidential and may incidentally match a declared literal. Plaintext restoration is a separate explicit action and is never included in the download.

02 / INSPECT

Inspect the saved sanitized boundary

Protect a request to inspect its sanitized frames, expiry and saved local status.

03 / REVEAL

Restore only by explicit action

Only a generated, unexpired result can be restored for its configured recipient fixture. Recipient labels are not authenticated user accounts. Restored plaintext appears only in this panel; changing input, inspecting another receipt or starting another operation clears it.

04 / REPLAY

Inspect local evidence and expiry

Saved receipts and audit entries contain sanitized evidence. Purging removes expired vault entries according to the server clock. Verification checks a stored local hash chain; it is not an external signature or administrator-proof guarantee.
