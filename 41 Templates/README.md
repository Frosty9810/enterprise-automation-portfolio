# Templates

> Status: **Populated**

## Purpose

Master, reusable templates for reusable documents in this portfolio. Every SOP, workflow doc, case study, ROI analysis, and executive summary across all 50 sections is expected to derive from one of these templates rather than inventing new structure.

## Contents

| File | Use When |
|---|---|
| [`sop-master-template.md`](sop-master-template.md) | Authoring any full 44-section Standard Operating Procedure for an automation project. |
| [`workflow-doc-template.md`](workflow-doc-template.md) | Documenting a smaller, standalone workflow that doesn't warrant a full SOP. |
| [`case-study-template.md`](case-study-template.md) | Writing an anonymized case study for [`43 Case Studies/`](../43%20Case%20Studies/README.md). |
| [`roi-analysis-template.md`](roi-analysis-template.md) | Producing the ROI Analysis section of any SOP, or a standalone ROI doc in [`44 ROI/`](../44%20ROI/README.md). |
| [`executive-summary-template.md`](executive-summary-template.md) | Writing content for [`00 Executive Summary/`](../00%20Executive%20Summary/README.md) or a client-facing deliverable. |

## Usage Rule

Copy the template into the destination folder and rename it to match the SOP/workflow/case study it documents. Never edit these files in place — they are the canonical source. Changes to the standard itself should be proposed and reviewed, then applied here and noted in [`49 Internal Standards/`](../49%20Internal%20Standards/README.md).
