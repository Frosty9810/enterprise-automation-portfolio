    Architecture and deliberate limits

    Browser → local API → original Python policy → SQLite receipt → human review → JSON handoff. The result is a proposal; no commerce API is called.

    Matching numbers and protected fields is a conservative rule check, not semantic translation validation. It can reject valid number formatting, and cannot detect every misleading sentence or unsupported claim in every language. A human still reviews the content. The hash-linked history detects accidental edits when independently verified; a database administrator can rewrite it. Production deployment needs source ownership, authenticated reviewers, access controls, and provider acceptance.
