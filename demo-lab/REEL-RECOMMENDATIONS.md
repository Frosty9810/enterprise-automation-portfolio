## Implemented in the portfolio

1. ECOM-01 and CON-01 lead the collection, followed by SAAS-03 and IMP-01. This is an editorial selection based on the clarity of demonstrable controls, not a benchmark ranking.
2. ECOM-01 results show the allowed and blocked content decisions with their reasons. New scenario suites show individual assertion outcomes. Raw output remains available in a disclosure panel.
3. Every project receives an execution map whose node names, types and outgoing edges come from its actual runnable n8n export. The full original workflow remains separately labeled source inventory.
4. Tool responsibilities are presented in a compact table, with evidence status and source links.
5. Twelve additional cases live in a separate regression file for the four roadmap builds. They are authored regression examples, not an unseen holdout, statistical evaluation or model-performance benchmark. Projects without these cases explicitly say so.
6. The outcome worksheet starts empty and computes review-time differences from user-provided observations. It allows negative improvements, rejects invalid inputs and does not save or export hypothetical ROI.
7. The interface uses restrained surfaces and accents, smaller evidence indicators and a clearer typographic hierarchy. HTML, CSS and JavaScript are now separate files. Inline script execution is removed from the site's content security policy.
8. Automated DOM checks exercise all 23 project selections, architecture details, measurement validation, search and failed-run presentation. This is not a screenshot or cross-browser visual audit.
