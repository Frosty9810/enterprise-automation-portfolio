## How This File Is Maintained

1. When a new SOP, workflow doc, or case study is authored, add a row here immediately — even if the video is not yet recorded (`Video Status: Pending`).
2. When a video is recorded, update the row's `Video Status` to `Recorded`, add the link and duration, and update the Coverage Summary counts.
3. This file is regenerated/reconciled at the end of each staged build session against the actual documents present, so it never drifts from reality.
