# Registered local industry desks

Each JSON manifest registers one implemented synthetic local desk for an existing catalog entry. The host accepts only the fixed legal, insurance and executive identifiers in `industry-desk-routes.mjs`; it never adds project counts or marks a full flagship complete. A feature adds its own manifest, core, fixtures, HTML, CSS, UI, tests and operating runbook. Missing executable files fail startup. No external address or arbitrary file path is accepted.

The host preserves the lab's loopback Host/Origin and POST intent boundary. Domain controllers own validation, durable state and human-review rules. This registry does not authenticate actors or authorize deployment, provider calls or real-world actions.
